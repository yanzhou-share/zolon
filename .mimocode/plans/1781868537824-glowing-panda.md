# 可嵌入智能客服 Widget 实现方案

## 目标
创建一个纯前端 JS Widget，可嵌入任意网站，右下角浮动按钮 + 弹出聊天面板，连接现有 FastAPI 后端。

## 需要创建/修改的文件

### 1. `widget.html` — 完整的可嵌入 Widget（新建）
### 2. `backend.py` — 添加 CORS 中间件（修改）
### 3. `demo.html` — 演示页面，测试嵌入效果（新建）

---

## 实现细节

### 1. `backend.py` 修改：添加 CORS

在 FastAPI app 创建后添加：

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],       # 允许所有来源（生产环境应限制）
    allow_methods=["*"],
    allow_headers=["*"],
)
```

位置：`backend.py` 中 `app = FastAPI(...)` 之后（约第33行附近）。

---

### 2. `widget.html` — 自包含 Widget

**结构**：单个 HTML 文件，所有 CSS/JS 内联，网站通过引入此文件即可使用。

**CSS 策略**：使用 `#ai-chat-widget` 作为根容器，所有样式加前缀避免冲突。不使用 Shadow DOM（保持简单，兼容性好）。

**UI 组件**：
- **浮动按钮**：右下角固定定位，圆形，带聊天气泡图标，有未读消息脉冲动画
- **聊天面板**：从按钮上方滑出，380px 宽 × 520px 高，包含：
  - 顶部标题栏（"智能客服" + 关闭按钮）
  - 消息列表区（可滚动）
  - 底部输入框 + 发送按钮
- **移动端适配**：全屏显示

**JS 功能模块**：
- `ChatWidget` 类：管理整体生命周期
- `sessionId`：首次访问生成 UUID，存入 localStorage，后续复用
- `chatHistory`：本地维护对话历史，每次请求发送给后端
- **流式渲染**：使用 `fetch()` + `ReadableStream` 解析 SSE（因为需要 POST 请求，不能用 EventSource）
- **Markdown 渲染**：简单的换行和粗体支持（轻量级，不引入库）
- **错误处理**：网络错误提示 + 重试按钮

**嵌入方式**（网站只需一行）：
```html
<script src="http://localhost:8000/static/widget.html" defer></script>
```

或者直接复制 widget.html 文件内容，在页面底部用 `<script>` 内联。

**Widget 自执行**：文件底部 `DOMContentLoaded` 事件自动初始化。

### 3. `demo.html` — 测试演示页

一个简单的 HTML 页面，模拟"任意网站"，包含：
- 任意占位内容（标题、段落）
- 底部引入 widget 的 script 标签
- 用于验证 Widget 在第三方页面中正常工作

## 关键技术方案

### SSE 流式解析（POST 方式）

```javascript
const response = await fetch(`${API_URL}/chat/stream`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ session_id, message, chat_history })
});

const reader = response.body.getReader();
const decoder = new TextDecoder();
// 逐行解析 event: token / event: done
```

### 消息数据结构

```javascript
// 发送
{ session_id: "uuid", message: "用户输入", chat_history: [...] }

// 接收 (SSE events)
// event: token → data: "部分文本"
// event: done  → data: {"reply":"完整回复","status":"normal","sentiment_label":"neutral",...}
```
