# 创建可外部引入的 Widget JS 文件

## 问题
`widget.html` 是完整 HTML 文档，不能用 `<script src>` 加载。外部页面（如用户自己的 index.html）无法正确引入。

## 修改方案

### 1. 创建 `static/widget.js` — 独立的 Widget JavaScript（新建）

从 `widget.html` 中提取 `<script>` 部分的内容，创建一个纯 JS 文件。

外部页面使用方式：
```html
<div id="ai-chat-widget"></div>
<script>window.AI_CHAT_API_URL = 'http://localhost:8000';</script>
<script src="http://localhost:8000/static/widget.js"></script>
```

CSS 样式需要通过 `<style>` 标签内联到使用页面，或者从 `widget.css` 加载。

### 2. 创建 `static/widget.css` — Widget 样式文件（新建）

从 `widget.html` 中提取 `<style>` 部分的内容。

### 3. 更新 `static/widget.html` — 改为引用 JS/CSS 文件

修改为引用独立的 CSS 和 JS 文件，保持功能一致。

### 4. 更新 `static/demo.html` — 使用新的引用方式

改为引入 `widget.js` 而非内联代码。

## 验证步骤

1. 重启后端服务
2. 用用户的 `index.html` 测试：
   ```html
   <div id="ai-chat-widget"></div>
   <script>window.AI_CHAT_API_URL = 'http://localhost:8000';</script>
   <script src="http://localhost:8000/static/widget.js"></script>
   <link rel="stylesheet" href="http://localhost:8000/static/widget.css">
   ```
3. 验证右下角出现聊天按钮，点击可打开面板
