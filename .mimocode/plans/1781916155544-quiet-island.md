## 1. 数据库迁移（JSON → SQLite）

**新建文件**: `database.py`

```python
import sqlite3
from datetime import datetime

DB_PATH = "saaS.db"

def init_db():
    conn = sqlite3.connect(DB_PATH)
    c = conn.cursor()
    
    # 用量记录表
    c.execute("""CREATE TABLE IF NOT EXISTS usage_logs (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        api_key TEXT NOT NULL,
        merchant_name TEXT,
        tokens_in INTEGER DEFAULT 0,
        tokens_out INTEGER DEFAULT 0,
        latency_ms REAL DEFAULT 0,
        status TEXT DEFAULT 'normal',
        created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
    )""")
    
    # 计费配置表
    c.execute("""CREATE TABLE IF NOT EXISTS billing_config (
        api_key TEXT PRIMARY KEY,
        price_per_1k_tokens REAL DEFAULT 0.01,
        monthly_free_quota INTEGER DEFAULT 10000,
        billing_cycle TEXT DEFAULT 'monthly'
    )""")
    
    conn.commit()
    conn.close()
```

## 2. 后端 API

**文件**: `backend.py`

### 2.1 记录每次请求用量

在 `/chat` 和 `/chat/stream` 响应后记录：

```python
def log_usage(api_key: str, merchant_name: str, tokens_in: int, tokens_out: int, latency_ms: float, status: str):
    conn = sqlite3.connect(DB_PATH)
    c = conn.cursor()
    c.execute("INSERT INTO usage_logs (api_key, merchant_name, tokens_in, tokens_out, latency_ms, status) VALUES (?, ?, ?, ?, ?, ?)",
              (api_key, merchant_name, tokens_in, tokens_out, latency_ms, status))
    conn.commit()
    conn.close()
```

## 4. 计费逻辑

### 4.1 计费配置

每个商户可配置：
- `price_per_1k_tokens`: 每千 Token 价格
- `monthly_free_quota`: 每月免费额度
- `billing_cycle`: 计费周期

### 4.2 账单生成

每月自动计算：
```
实际用量 = 总 Token - 免费额度
费用 = 实际用量 / 1000 × 单价
```
