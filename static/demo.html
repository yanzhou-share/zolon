如何集成到你的网站

1

设置 API 地址

在 Widget 加载前设置后端地址：

<script>window.AI_CHAT_API_URL = 'https://your-api-domain.com';</script>
2

设置 API Key

配置商户 API Key（从管理后台获取）：

<script>window.AI_CHAT_API_KEY = 'zk_your_api_key';</script>
3

引入 Widget

只需一行代码即可集成：

<script src="http://your-server:8000/static/widget.js"></script>
