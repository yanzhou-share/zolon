# 故障排除指南

## 手机常见问题

### 充电异常
问题：MP12充电速度变慢
解决方案：
1. 检查充电器是否为原装100W快充
2. 清理充电口灰尘
3. 关闭省电模式
4. 避免边充边用

问题：无线充电不工作
解决方案：
1. 确认放置位置正确（对准线圈）
2. 移除手机壳（金属壳不兼容）
3. 检查充电器是否支持Qi协议

### 相机问题
问题：拍照模糊
解决方案：
1. 清洁镜头
2. 检查是否开启了AI增强
3. 在设置中重置相机参数

问题：夜景模式效果差
解决方案：
1. 保持手稳或使用三脚架
2. 确保场景有足够光源
3. 在专业模式下调整ISO和快门

### 网络问题
问题：5G信号不稳定
解决方案：
1. 检查SIM卡是否支持5G
2. 在设置中重置网络
3. 联系运营商确认套餐

## 手表常见问题

问题：心率监测不准
解决方案：
1. 确保佩戴松紧适中
2. 清洁传感器区域
3. 避免在纹身或疤痕处佩戴

问题：无法同步数据
解决方案：
1. 确认蓝牙已开启
2. 在手机APP中重新配对
3. 重启手表和手机

## 耳机常见问题

问题：降噪效果变差
解决方案：
1. 清洁耳机出音孔
2. 检查耳塞是否佩戴正确
3. 在APP中重置降噪设置

问题：断连频繁
解决方案：
1. 清除配对记录重新连接
2. 更新固件版本
3. 避免与WiFi路由器距离过近

## 笔记本常见问题

问题：运行缓慢
解决方案：
1. 检查任务管理器关闭后台程序
2. 清理C盘空间（保持20%以上）
3. 运行Windows更新
4. 考虑升级到32GB内存版本

问题：风扇噪音大
解决方案：
1. 清理散热口灰尘
2. 使用散热底座
3. 在电源管理中选择"平衡"模式
4. 避免在柔软表面使用

问题：电池续航短
解决方案：
1. 降低屏幕亮度
2. 关闭不用的蓝牙和WiFi
3. 在电源管理中选择"节能"模式
4. 检查电池健康度（设置-电池）
